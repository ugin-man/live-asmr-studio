# Live ASMR Studio v0.15.1

This folder is the unpacked Manifest V3 extension and the root of the GitHub release ZIP.

Load this folder from `chrome://extensions` or `brave://extensions` with Developer mode enabled. Open ChatGPT Voice Live, start a voice response, keep that tab active, and click the Live ASMR Studio toolbar icon. The side panel then controls the local Web Audio processing graph.

The extension bundles its measured Aalto near-field HRTF data. It does not load remote code or HRTF data, record audio, capture a microphone, or send captured audio to an extension-operated server.

See the project [README](https://github.com/ugin-man/live-asmr-studio#readme), [privacy policy](PRIVACY.md), [support guide](SUPPORT.md), [change log](CHANGELOG.md), and [third-party notices](THIRD_PARTY_NOTICES.md). These local documentation links also work in the release ZIP.
