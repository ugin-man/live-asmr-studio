# Live ASMR Studio support

## Requirements

- Chrome or Brave 116 or later
- Stereo headphones or earphones
- A tab that can play ChatGPT Voice Live audio

## If audio does not connect

1. Start a voice response in ChatGPT Voice Live.
2. Keep that tab active.
3. Click the Live ASMR Studio toolbar icon.
4. Check the target tab and error text at the top of the side panel.

Repeat the toolbar click after switching to another source tab. The prior capture and toolbar badge should stop automatically.

## If the audio is too loud

Lower the headphone or system volume first. The extension shows a one-time warning before entering 10× gain or higher. The peak limiter reduces clipping; it is not hearing protection.

## Resetting a broken setup

Export your settings from **Detailed settings → Settings management**, then use **Reset to defaults**. If the problem remains, include the extension version, browser version, complete error text, target tab title, and reproduction steps in a bug report.

## 日本語

接続できない場合は、ChatGPT Voice Liveで音声返答を開始し、そのタブを前面にしたままLive ASMR Studioのツールバーアイコンを押してください。サイドパネル上部の対象タブとエラー全文を確認します。別タブへ切り替えた場合も、新しいタブを前面にしてアイコンを押し直します。

音が大きい場合は、先にヘッドホンかOS側の音量を下げてください。10倍以上へ入る前の警告は初回だけ表示します。ピークリミッターは音割れを減らすもので、聴力を保護する機能ではありません。

設定がおかしい場合は、「詳細設定 → 設定の管理」から設定を書き出し、「設定を初期値へ戻す」を使ってください。不具合報告には拡張機能のバージョン、ブラウザのバージョン、エラー全文、対象タブ名、再現手順が必要です。
