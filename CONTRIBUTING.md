# Contributing

Bug reports, translations, documentation fixes, and focused code changes are welcome.

Before opening a pull request:

1. Keep the extension's purpose limited to local ASMR processing for user-selected voice tabs.
2. Do not add remote code, tracking, advertising, or audio uploads.
3. Preserve import compatibility for settings exported by older releases when practical.
4. Run all four Node.js checks listed in the README.
5. Load the `extension` folder unpacked and verify the changed side-panel flow in Chrome or Brave.

For audio changes, describe the headphones used, source material, comparison settings, and whether perceived loudness was matched. Do not claim an improvement from loudness alone.

By contributing, you agree that your contribution may be distributed under the MIT License. Dataset or media contributions must include their source and license.
