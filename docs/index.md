# Live ASMR Studio

Live ASMR Studio is a free, open-source Chrome extension that turns a user-selected ChatGPT Voice Live tab into a spatial ASMR listening session. Measured near-field HRTF positioning, movement, voice texture, ambience, and prompt templates run locally in the browser.

- [Privacy policy](privacy.md)
- [Support](support.md)
- [Source and installation instructions](../README.md)

Live ASMR Studio is an independent project. It is not affiliated with, endorsed by, or sponsored by OpenAI.
