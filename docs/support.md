# Support

Live ASMR Studio requires Chrome or Brave 116 or later, stereo headphones or earphones, and a tab that can play ChatGPT Voice Live audio.

## Connection checklist

1. Start a voice response in ChatGPT Voice Live.
2. Keep that tab active.
3. Click the Live ASMR Studio toolbar icon.
4. Check the target tab and error text at the top of the side panel.

Repeat the toolbar click after switching to another source tab. The previous capture and toolbar badge should stop automatically.

## Sound safety

Lower the headphone or system volume before using high extension gain. A one-time warning appears before entering 10× gain or higher. The peak limiter reduces clipping; it is not hearing protection.

## Bug reports

After the repository is published, use its GitHub issue tracker for ordinary bugs. Include the extension version, browser version, complete error text, target tab title, and reproduction steps. Do not include private conversations or settings exports unless you have removed personal content.

For a security issue, follow the repository's `SECURITY.md` and do not disclose vulnerability details in a public issue.

## 日本語

Live ASMR Studioの動作条件は、ChromeまたはBrave 116以降、ステレオヘッドホンまたはイヤホン、ChatGPT Voice Liveの音声を再生できるタブです。

接続できない場合は、ChatGPT Voice Liveで音声返答を開始し、そのタブを前面にしたままLive ASMR Studioのツールバーアイコンを押してください。サイドパネル上部の対象タブとエラー全文を確認します。別タブへ切り替えた場合も、新しいタブを前面にしてアイコンを押し直します。

音が大きい場合は、先にヘッドホンかOS側の音量を下げてください。10倍以上へ入る前の警告は初回だけ表示します。ピークリミッターは音割れを減らすもので、聴力を保護する機能ではありません。

不具合報告には拡張機能のバージョン、ブラウザのバージョン、エラー全文、対象タブ名、再現手順が必要です。個人的な会話や、個人情報を含む設定ファイルは添付しないでください。
