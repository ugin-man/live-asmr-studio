# Live ASMR Studio v0.15.0

The first public release of Live ASMR Studio: a free, open-source Chromium extension that turns a user-selected ChatGPT Voice Live tab into a spatial ASMR listening session.

## Highlights

- Measured near-field HRTF positioning with a draggable listener map
- Smooth behind-the-head, orbit, alternating-ear, and close-to-far return motion
- Voice texture, low-band pressure, ambience, and output gain controls
- Session prompts for conversation, sleep, focus, role-play, onomatopoeia, and imported text
- English, Japanese, Simplified Chinese, Korean, and Spanish UI and generated prompts
- Local-only audio processing with no recording, analytics, ads, or extension-operated server

## Added in 0.15.0

- Moved full-cycle and one-way motion timing into the normal spatial controls
- Added left-ear and right-ear pull-away-and-return motion while preserving the 110-degree ear position
- Added an authored onomatopoeia session mode with short, standard, and long scene flows
- Added prompt guardrails against rushed lists, unnatural syllable splitting, and excessive explanation

## Install

1. Download `live-asmr-studio-v0.15.0.zip` below.
2. Extract it to a permanent folder.
3. Open `chrome://extensions` or `brave://extensions`.
4. Enable Developer mode.
5. Choose **Load unpacked** and select the extracted folder.

For later updates, replace the files in the same folder and press **Reload** on the extension card.

Use stereo headphones at a low device volume first. High extension gain can become dangerously loud.
