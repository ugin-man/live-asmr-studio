# Chrome Web Store listing copy

## English

Name: `Live ASMR Studio`

Summary: `Spatial ASMR audio for ChatGPT Voice Live with measured HRTF positioning, motion, ambience, and session prompts.`

Detailed description:

> Turn a ChatGPT Voice Live session into spatial ASMR, directly in your browser.
>
> Live ASMR Studio captures audio only from the tab you choose with a toolbar click. It then processes that audio locally with measured near-field HRTF data. Place the voice around your head with a draggable map, move it smoothly between the ears, add subtle room ambience, and shape the sound for a closer ASMR presentation.
>
> Create a session in a few clicks with authored flows for conversation, sleep, focus, role-play, spoken onomatopoeia, or your own text. Copy the generated prompt into ChatGPT Voice Live, start the response, and connect the tab from the extension icon.
>
> Highlights:
> • measured near-field binaural positioning
> • smooth rear sweep, orbit, alternating-ear, near-to-far return, and random motion
> • voice texture, low-band pressure, early reflections, ambience, and gain controls
> • five interface and prompt languages
> • local settings export and import
> • no recording, ads, analytics, or audio upload
>
> Stereo headphones or earphones are required. Start at a low device volume. The limiter reduces clipping and is not hearing protection.
>
> Live ASMR Studio is an independent project. It is not affiliated with, endorsed by, or sponsored by OpenAI.

## Store declarations

Single purpose: locally transform audio from a user-selected voice tab into a configurable spatial ASMR session and generate related session prompts.

Permission justifications:

- `activeTab`: identify the active tab only after a direct toolbar action
- `tabCapture`: capture the chosen tab's audio for local Web Audio processing
- `offscreen`: keep the processing graph alive when the side panel loses focus
- `sidePanel`: provide the product controls next to the source tab
- `storage`: retain user-selected sound, language, prompt, and session settings locally
- `clipboardWrite`: copy a generated prompt only after the user presses a copy button

Data disclosures:

- Handles website content: user-entered prompt settings or imported text stored locally
- Handles audio: transient tab audio processed locally and never recorded or transmitted by the extension
- No sale, advertising use, analytics use, credit use, or human review of user data
- No remote code and no host permissions
